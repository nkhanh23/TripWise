# T003 official-source candidate matrix — 2026-09-08

Research in this run used official vendor documents only. Documentation coverage is not live API proof. No subscriptions, orders, account registrations or paid terms were accepted. Historical RBA approvals remain superseded. `UNRESOLVED` means evidence insufficient for the particular requirement, not a finding that the provider has no rights.
